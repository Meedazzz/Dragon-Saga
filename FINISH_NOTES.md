# Dragon Saga — финальная доработка

Сборка проверена командой `npm run build`. Готовая production-версия лежит в `dist/`.

## Что изменено

- Усилен первый экран: тёмное фэнтези, CTA к Таро, миру и летописи.
- Карты Таро превращены в центральный интерактивный оракул:
  - 5 карт героев с общей рубашкой;
  - веер на десктопе;
  - мобильная карусель с индикатором;
  - 3D-наклон мышью;
  - переворот колесом мыши;
  - свайп на мобильных;
  - режим лора с переходами без перезагрузки.
- Добавлены нарративные значения карт на основе лора сайта:
  - расклад 3 карты: Прошлое / Настоящее / Будущее;
  - 50% шанс перевёрнутого положения;
  - расклад по вопросу с распознаванием фокуса вопроса;
  - мини-игра «Сцена оракула»: карта + d20 + НРИ-последствие;
  - карта дня по локальной дате.
- Фон частиц заменён на падающий снег/пепел, включён и на мобильных в облегчённом режиме.
- Уроборос добавлен в переходы/лоадер персонажных страниц.
- Прокрутка закреплена: при переходах страница открывается сверху, scroll restoration отключён.
- Удалены блокировки контекстного меню/копирования из приложения, чтобы вики было удобнее исследовать.

## Деплой

Для GitHub Pages можно использовать содержимое `dist/` или стандартный пайплайн Vite. В `vite.config.ts` установлен `base: '/Dragon-Saga/'`.
