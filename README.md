## Установка

1. Распакуйте архив в корень проекта (файлы автоматически лягут по правильным путям)
2. Убедитесь, что зависимости установлены:
   ```bash
   npm install framer-motion lucide-react
   ```
3. Проверьте пути к изображениям в `src/data/tarot.ts`:
   - `shirt.png` — рубашка карт (должна быть в `public/`)
   - `tarot_*.png` — лицевые стороны карт
4. Запустите:
   ```bash
   npm run dev
   ```
