# 📋 Файлы изображений для добавления

Все файлы нужно положить в папку `public/` проекта.

Эти изображения отображаются на странице лора каждого персонажа (круглые, вместо карт таро).
Рекомендуемый размер: **400×400 px** или больше (квадратные).

| Файл | Описание |

| `public/avatar_valery.png` | Аватарка Валерия Даркбейна |

| `public/avatar_sakris.png` | Аватарка Сакриса Ульриаша |

| `public/avatar_stive.png` | Аватарка Стива |
